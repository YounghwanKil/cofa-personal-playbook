현장 복붙: 제한시간 문제 해결 플레이북

자동 에이전트 설치기가 아니라 운영 문서와 프롬프트 모음입니다.
공식 규정에서 허용된 도구·자료만 사용합니다. Git과 Python 3이 필요합니다.

1. 제공 과제 폴더의 터미널을 여세요. pwd로 위치를 확인하세요.
아래 괄호 시작부터 끝까지 복사하면 준비 자료를 별도 임시 폴더에 받습니다.
과제 폴더와 기존 Git 설정은 수정하지 않습니다. 재실행 시 새 폴더를 만듭니다.
표시되는 폴더는 대회가 끝날 때까지 지우지 마세요.

(
set -eu
COFA_READY_DIR=$(mktemp -d "${TMPDIR:-/tmp}/cofa-ready.XXXXXX")
git clone --depth 1 --branch finals-preparation https://github.com/YounghwanKil/cofa-personal-playbook.git "$COFA_READY_DIR/kit"
python3 - "$COFA_READY_DIR/kit" <<'PY'
from pathlib import Path
import re, sys
kit = Path(sys.argv[1]).resolve()
blocks = re.findall(r'```text\n(.*?)```', (kit / 'prompts/FINALS_A.md').read_text(), re.S)
prompt = blocks[0].replace('준비 자료 경로는 [절대 경로], 실제 과제 루트는 [절대 경로]다.', f'준비 자료 경로는 {kit}, 실제 과제 루트는 {Path.cwd()}다.')
p = kit.parent / 'A_START.txt'
p.write_text(prompt, encoding='utf-8')
print('시작 프롬프트 파일:', p)
print('아래 내용을 AI에 복사하고 [분]과 [시각]을 실제 값으로 바꾸세요.')
print(prompt)
PY
git -C "$COFA_READY_DIR/kit" rev-parse HEAD
)

2. 출력된 프롬프트를 실제 과제 폴더에서 연 AI 대화창에 붙이세요.
남은 시간과 마감을 채우세요. 최초 분석은 15~20분 목표이며 계획 확인 후 시작합니다.

3. 계획 확인 후 AI에:

계획을 확인했다. 구현 시작. 남은 시간은 [분]이다.
준비 자료 prompts/FINALS_A.md의 '계획 확인 후' 블록을 따라라.
첫 정상 실행과 필수 요구 충족을 우선하고 문서·도구·기능을 불필요하게 늘리지 마라.

4. 첫 결과가 나오면 같은 AI에:

현재 버전을 기록하고 수정은 잠깐 멈춰라.
공식 수락 조건과 정상 입력, 틀리기 쉬운 핵심 입력으로 실제 검증해라.
반도체라는 이유로 문제에 없는 공정 규칙을 추가하지 마라.
실패하면 재현→원인→최소 수정→재검증으로 처리해라.
별도 B 검토가 필요하면 경로와 버전을 채운 FINALS_B 프롬프트를 만들어줘.
사본은 동시 수정이나 데이터 손상 위험이 있을 때만 준비해라.

5. 마지막 약 20% 시간이 남으면:

선택 기능 추가를 멈춰라. 필수 요구·실행 오류·제출 검증을 우선해라.
실제 제출 폴더에서 실행하고 공식 형식의 제출물 목록을 확인해라.
설명이 요구되면 선택 이유·검증 결과·한계를 한 페이지 이내로 정리해라.
미완료와 미검증을 숨기지 마라.

6. 세션 복구:

이 과제를 이어서 진행한다. 준비 자료 경로는 [다운로드 폴더/kit]다.
