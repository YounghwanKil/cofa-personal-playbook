## 볼 문서는 3개

1. **[QUICKSTART.md](QUICKSTART.md)** — 입장 직후부터 마무리까지 복붙 순서.
2. **[핵심 질문 7개](docs/핵심질문7개.md)** — 가장 중요한 복습 자료. 과거 기출 유형 기반 예상 질문과 실제 코드에서 준비할 근거.
3. **[START_HERE.md](START_HERE.md)** — 에이전트 작업 규칙과 막혔을 때 사용하는 명령.

추가 자료: [6쪽 PDF](pdf/COFA_PLAYBOOK.pdf) · [빈 구현 설명 양식](templates/PROJECT_DEFENSE.md)

## 1. 과제 폴더 터미널에서

```sh
git clone --depth 1 https://github.com/YounghwanKil/cofa-personal-playbook.git .cofa-playbook
```

clone 뒤에도 제공 과제 폴더에 머무릅니다. 이미 내려받았고 준비 문서를 수정하지 않았다면 `git -C .cofa-playbook pull --ff-only`로 갱신합니다.

## 2. 제공된 Codex 대화창에서

```text
현재 폴더의 제공 과제가 구현 대상이고 .cofa-playbook은 참고 자료다.
.cofa-playbook/START_HERE.md의 1번 시작 프롬프트를 적용해라.
남은 시간은 [180분]이다. 공식 README·AGENTS·응시 지침이 우선이다.
첫 사용자 흐름을 실행하고 나머지 필수 요구까지 구현·검증해라.
메인은 핵심 흐름·통합·기록을 맡고 독립 작업만 서브에이전트에 배정해라.
.cofa-playbook/docs/핵심질문7개.md를 설명 준비의 기준으로 삼아라.
실제 선택 이유·모듈·데이터 흐름·조건 변경·수정 사례·가정·실패 대응을
현재 코드와 검사 근거로 기록하고 배포 방식도 짧게 정리해라.
과거 문제의 주제나 알고리즘을 이번 과제에 억지로 적용하지 마라.
과제 코드와 실제 작업 기록은 과제 폴더에 두고 준비 저장소에 올리지 마라.
현재 상태와 첫 실행 방법을 짧게 보고하고 진행해라.
```

## 3. 이후 운영

고객 답변을 전달하고, 실제 화면을 확인하고, 남은 시간을 알려줍니다. 상세 복붙 문구는 [QUICKSTART.md](QUICKSTART.md)에 있습니다. 마지막에는 핵심 7문항과 배포 방식을 실제 구현에 맞춰 정리하고, 허용된 사전 연습 시간에 답을 가린 리허설을 합니다.

실제로 구현한 것·검증한 것·한계를 구분합니다. 별도 스킬 설치나 상시 기록 전담 에이전트는 필요하지 않습니다.
