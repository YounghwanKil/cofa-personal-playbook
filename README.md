# COFA 개인 실행 플레이북

낯선 개발 과제를 요구 분석 → 첫 동작 흐름 → 독립 작업 병렬화 → 통합 검증 → 구현 설명 연습으로 진행하는 한국어 준비 자료입니다. 공식 키트나 출제 예측 자료가 아닙니다.

## 시험장 시작: 터미널에 입력

**제공된 과제의 최상위 폴더에서** 실행합니다. clone 후에도 과제 폴더에 그대로 머무릅니다.

```sh
git clone --depth 1 https://github.com/YounghwanKil/cofa-personal-playbook.git .cofa-playbook
```

이 명령은 자료만 내려받습니다. 패키지를 설치하거나 기존 README·AGENTS를 덮어쓰지 않습니다. 같은 폴더가 이미 있으면 삭제하지 말고 기존 자료를 먼저 확인합니다.

## 다음: 제공된 Codex 대화창에 입력

아래의 남은 시간만 실제 값으로 바꿉니다.

```text
현재 작업 디렉터리의 제공 과제가 구현 대상이다.
.cofa-playbook은 참고 자료 폴더이며 구현 대상이 아니다.
.cofa-playbook/START_HERE.md를 읽고 1번 시작 프롬프트를 적용해라.
현재 남은 시간은 [예: 180분]이다.
공식 README·AGENTS·응시 지침이 우선이며, 기존 스택과 실행 방식을 확인해라.
과제 폴더에 계획과 실제 구현 근거를 남기고 구현·검증까지 진행해라.
이 자료 폴더나 원격 준비 저장소에 실제 과제 코드·고객 답변·작업 기록을 올리지 마라.
필요한 후속 명령은 START_HERE.md에서 현재 단계에 맞춰 적용해라.
```

## 운영 원칙

메인이 핵심 흐름·공유 계약·통합·공통 기록을 맡고, 독립 작업이 있을 때 구현 서브에이전트 1~2명을 사용합니다. 워크트리는 지원 환경과 격리 필요에 맞춰 선택합니다. 독립 검토는 첫 흐름과 최종 통합 시점에 수행합니다. 상시 기록 전담 에이전트는 두지 않습니다.

공식 필수 요구는 끝까지 구현합니다. 중요한 선택은 이유·실제 코드·검증·한계로 연결하며, 사용하지 않은 모듈이나 실행하지 않은 검사를 답변에 넣지 않습니다. 실전 Q&A에서의 AI 사용 여부 등은 현재 공식 규정을 따릅니다. 이 자료는 허용된 구현·사전 연습 시간에 사용합니다.

작성 기준: 2026-11-05. 공개 저장소의 최신 상태와 해당 회차의 규칙은 별도 확인해야 합니다. 외부 저장소 코드는 동봉하지 않았으며 원문 링크를 제공합니다.
